# Alternative extra-spectrum note

The localized identification extension is sufficient, so no alternative method is needed.

- A full-spectrum or nuclear pilot would require an independent operator-rate theorem for its estimator and
  would not be simpler than extending the existing fixed-rank curvature domain.
- A residual-score estimate of the post-cap noise singular value would be a new statistical construction and
  would need its own normalization and perturbation proof.
- No other extra-spectrum construction in the current manuscript already supplies the needed genuine
  `(bar_r_M+1)`st value together with the generic operator rate.

These observations are comparative only. RR2.5 does not develop, tune, implement, or test an alternative. It
does not reduce reporting caps or assume that truth is strictly below a cap.
