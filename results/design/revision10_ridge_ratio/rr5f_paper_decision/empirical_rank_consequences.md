# Empirical rank consequences

Under Route A, ranks are handled as transparent specification inputs.

## Prespecified workflow

1. Define a small rank grid before computing headline target estimates, respecting subject-matter plausibility, panel dimensions, and fixed reporting caps.
2. Name one baseline supplied-rank vector using an ex-ante specification rationale, not whichever vector produces favorable estimates.
3. Report neighboring supplied-rank target estimates and confidence intervals using the theorem appropriate to each supplied fit.
4. Report fit, residual, boundary-activity, stationarity, numerical-rank, and raw singular-value diagnostics descriptively.
5. Distinguish conclusions stable across the grid from conclusions sensitive to rank specification.

Singular-value or fit diagnostics may inform interpretation, but they must not be labeled a consistent selected rank. If the baseline rank uses a conventional empirical criterion outside the paper's theory, identify it as a specification convention and retain the full sensitivity display.

The empirical section must not claim rank-robust inference, post-selection validity, or automatic factor-number consistency. It should emphasize that uncertainty statements are conditional on each supplied-rank specification.

Route A+ would use the identical empirical workflow; its auxiliary theorem cannot choose empirical ranks until a pilot satisfying its premise is computationally available. Routes B and C currently have no defensible empirical workflow.
